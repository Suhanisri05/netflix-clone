# 🎬 Netflix Clone
# Overview 

A responsive frontend clone of the Netflix landing page built using **HTML and CSS**  
This project was created to practice frontend development, responsive layouts, and recreating real-world website interfaces

## 🚀 Features

- ✅ Netflix-inspired landing page
- ✅ Responsive design for different screen sizes
- ✅ Navigation bar
- ✅ Hero/banner section
- ✅ Content sections
- ✅ FAQ section
- ✅ Language selection option
- ✅ Footer with useful links
- ✅ Netflix-inspired UI and styling

## 🛠️ Technologies Used

- HTML5
- CSS3
